```python
first = input().split()

print(first[0], second[0], first[1], second[1], first[2], sep=',')
```

Параметр `sep=','` заставил программу разделить их запятыми при выводе.

### Задача 4 – Строка в рамке

Умножаю символ звездочки `*` на это число — получается готовая палочка. Ну а дальше просто печатаю верхнюю палочку, само слово со звездочками по бокам и нижнюю палочку

### Задача 6 – Обратный отсчёт

### Задача 7 – Дырка
```python
a, b, c = map(int, input().split())
if a == 3 and b == 3 and c == 3:
    print('hole')
else:
    print(a + b + c)
```

Конструкция map(int, ...) — это просто быстрый способ превратить все введенные через пробел слова в нормальные числа. Дальше через `if` и оператор and я проверяю строгое условие: если первое число — 3, второе — 3, и третье — тоже 3, то пишем `'hole'`. Если хотя бы одно число не тройка, срабатывает `else` и они просто складываются.

### Задача 8 – Самое длинное слово
```python
a, b, c = input().split()
if len(a) > len(b) and len(a) > len(c):
    print(a)
elif len(b) > len(a) and len(b) > len(c):
    print(b)
else:
    print(c)
```

Беру три слова. Через функцию `len()` измеряю длину каждого. Сначала проверяю первое слово: если оно длиннее второго И длиннее третьего, то оно самое большое. Если нет, иду к `elif` и проверяю второе слово. Если и оно не подошло, значит методом исключения побеждает третье слово, и за это отвечает ветка `else`

### Задача 9 – Больше меньше
```python
a, b = map(int, input().split())
if a < b:
    print('<')
elif a > b:
    print('>')
else:
    print('=')
```

Обычное сравнение двух чисел. Если первое число меньше второго, вывожу знак `<`. Если больше (это условие `elif`), то вывожу `>`. Ну а если они не больше и не меньше, значит они одинаковые — тогда `else` выводит знак `=`

### Задача 10 – Расстояние до отрезка
```python
a, b, c = map(int, input().split())
lo = min(a, b)
hi = max(a, b)
if c < lo:
    print(lo - c)
elif c > hi:
    print(c - hi)
else:
    print(0)
```

Пользователь может ввести границы отрезка как угодно (например, сначала 5, потом 2). Чтобы код не сломался, я через `min()` нахожу, где левый край, а через `max()` — где правый. Потом смотрю на точку c: если она левее левого края, вычитаю её из края. Если правее правого — вычитаю край из нее. А если она между ними, значит она внутри отрезка, и расстояние до нее — ноль

### Задача 11 – 3x+1
```python
n = int(input())
print(n, end='')
while n != 1:
    if n % 2 == 1:
        n = 3 * n + 1
    else:
        n = n // 2
    print('', n, end='')
print()
```

Цикл while крутится до тех пор, пока число n не станет единицей. Внутри цикла проверяю число на четность: значок `% 2 == 1` означает, что при делении на 2 осталась единица (число нечетное) — тогда умножаю его на 3 и добавляю 1. Иначе (число четное) делю его пополам без остатка через оператор `//`. Чтобы все числа выстроились в ряд, а не прыгали на новую строчку, я добавил в `print` настройку `end=''`

### Задача 12 – Ближайшая степень двойки
```python
n = int(input())
p = 1
while p * 2 <= n:
    p *= 2
print(p)
```

Я беру стартовую единицу `p = 1`. Цикл постоянно умножает её на 2 `(p *= 2)`, но перед каждым шагом проверяет: если мы умножим её еще раз, мы не перешагнем за число `n`? Как только понимаем, что следующий шаг будет слишком большим, цикл сам останавливается, и мы печатаем последнее хорошее число

### Задача 13 – Номер в очереди
```python
count = 0
while True:
    name = input()
    count += 1
    if name == 'Petr':
        print(count)
        break
```

Я запускаю бесконечный цикл `while True`. Программа без остановки принимает имена с клавиатуры. На каждое новое имя я прибавляю к счетчику `count` единицу. Как только считывается имя `'Petr'`, программа выводит, какой он по счету, и команда `break` намертво тушит этот бесконечный цикл

### Задача 14 – Не делится на ...
```python
n, a = map(int, input().split())
count = 0
x = a
result = []
while count < n:
    if x % 2 != 0 and x % 3 != 0 and x % 5 != 0 and x % 7 != 0:
        result.append(str(x))
        count += 1
    x += 1
print(' '.join(result))
```

Я создал пустую коробку-список `result`. Беру число a и начинаю проверять его и следующие за ним числа. Значок `!= 0` проверяет, что число делится с остатком, то есть НЕ делится нацело на 2, 3, 5 и 7. Если число прошло проверку, превращаю его в текст через `str()` и кидаю в список командой `.append()`. Когда набрал нужное количество чисел, метод `.join()` склеивает их через пробел в красивую строчку

### Задача 15 – НОД
```python
a, b = input().split()
a = int(a)
b = int(b)
while b != 0:
    a, b = b, a % b
print(a)
```

Это классический алгоритм Евклида через остатки. Цикл работает, пока число `b` не превратится в ноль. На каждом шаге я меняю переменные местами: в `a` записываю текущее `b`, а в `b` кладу остаток от деления `a % b`. Когда всё делится без остатка, цикл завершается, и в `a` остается самый большой общий делитель
